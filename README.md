# Arcanum: Spellbound Realms

A fantasy spell-casting incremental game. Cast arcane spells, learn incantations in the Grimoire, improve enchantments, awaken magical realms, and unlock Arcane Forms.

## Play
Open [the GitHub Pages game](https://staynotnice.github.io/TREE-CUTTER/) or open `index.html` in a modern browser.

## How to play
- Click the crystal or **Cast** button to gather mana.
- Learn incantations and buy enchantments in the **Grimoire**.
- Awaken new realms to multiply spell power.
- Unlock and equip **Arcane Forms**; each description explains its look and any special bonus.
- Open **Settings → Open goals** to visit the dedicated **Prophecy Journal**, with live progress bars and completed goals.
- Progress saves automatically in this browser. Settings lets you export or import a backup.

Saves are local to this browser and do not automatically sync between devices. Export a backup before clearing browser data.
